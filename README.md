# Agenda — Controle de Serviços

Protótipo front-end feito com HTML, CSS e JavaScript puro, inspirado na estética roxa/lilás do protótipo visual.

## Como executar
1. Extraia o ZIP.
2. Abra `index.html` no navegador. Não precisa instalar dependências nem configurar servidor.
3. Os cadastros ficam salvos no `localStorage` do navegador.

## Telas incluídas
- Dashboard com indicadores, gráfico ilustrativo, serviços mais agendados, próximos agendamentos e clientes recentes.
- Agendamentos: busca, cadastro, edição e exclusão.
- Serviços: cadastro, edição, exclusão e validação de valor positivo.
- Clientes: cadastro, edição, exclusão e validação básica de e-mail duplicado.
- Usuários: cadastro, edição e exclusão.
- Tipos de acesso: cadastro, edição e exclusão.

## Observações
Este é um protótipo front-end. Não possui backend, autenticação real nem banco de dados compartilhado. Os dados são exemplos e ficam no navegador. Regras como conflito de horário e exclusão de serviços/clientes vinculados têm validações básicas no JavaScript; para entrega acadêmica completa, as validações e persistência também devem ser implementadas no backend exigido pelo enunciado.
